# 002. 중단 시점을 학습 모델로 자동화하지 않기로 했다

2026-09-23. 의논을 언제 끝내고 결과물을 쓸지(STOP)와 더 의논할지(CONTINUE)를 학습 모델로 정할지 실험으로 판정했다.

## 미리 정한 규칙

상수 예측(항상 멈춤 또는 항상 계속)보다 나은 학습 모델이 없으면 만들지 않는다. 실험 전에 이 규칙과 평가 기준을 먼저 적어 두고, 결과를 보고 규칙을 바꾸지 않았다.

## 실험

- 기록된 대화 상태 12개(과제 5종, 참여자 Groq + Claude)마다 STOP(지금 작성)과 CONTINUE(한 바퀴 더 의논 뒤 작성)를 같은 평가 기준·작성자·채점자로 돌렸다.
- 라벨은 상태 10건(비교자 호출 실패 2건 제외).

## 결과

| 항목 | STOP | CONTINUE |
|---|---|---|
| 평균 모델 호출 | 2.0회 | 5.6회 |
| 평균 소요 | 52초 | 109초 |
| 평가 점수 | 12개 중 10개 상태에서 같거나 높음 | |

- 중단 시점 학습 모델의 정확도는 50%로, "항상 멈춤"의 60%를 넘지 못했다(라벨 10건).
- 같은 상태를 두 번 라벨링한 7건 중 3건만 같았다(43%). 작업 폴더 격리 전후의 다른 조건 비교라 재현율의 상한으로 읽지 않는다.

## 판정

규칙대로 학습 모델을 만들지 않았다. 대신 "한 바퀴 의논 뒤 작성"을 고정 예산으로 쓴다. 상태가 더 쌓여 상수 예측을 넘는 모델이 나오면 그때 다시 본다.

## 한계

상태 12·라벨 10은 작은 표본이다. 품질 비교는 LLM 채점(블라인드)이며 사람 평가가 아니다. 과제가 짧다. 실험 코드는 원본 정리 때 보관으로 옮겨 이 저장소에 없고, 수치는 원본 DB `session_outcomes`·`model_calls`에서 다시 센 값이다.
