# 001. CLI 실패 메시지가 참여자 발언으로 기록돼 분석 기록을 오염시켰다

2026-09-23. 중단 시점 판정 규칙을 만들려고 수집 실행 대화 8개의 사회자 판정 기록 21건을 분석하던 중 발견했다. 원인 설명은 2026-10-04 저장 기록과 런타임 시험으로 다시 확인해 고쳤다.

## 무엇이 잘못됐나

Codex 발언 10회 중 8회가 발언 자리에 Codex CLI의 실패 메시지로 저장돼 있었다(대화 2개에 몰림). 메시지는 실행 배너 뒤에 사용 한도 초과 오류 줄이 붙은 모양이었다.

```
[A] Reading additional input from stdin...
    OpenAI Codex v0.155.1
    workdir: (경로)
    ...
    ERROR: You've hit your usage limit. ...
```

같은 메시지가 이어진 자리에서는 분석용 반복 지표(`repeat_ratio`)가 1.00이 됐다. 이 기록으로 중단 규칙을 학습하면 "같은 말을 반복 중"이라는 틀린 신호를 배운다. 사회자가 실제로 "맴돈다"고 판정한 기록은 없다.

## 원인

- **확인한 원인.** `Codex.parse()`가 본문이 비면 `stderr`를 그대로 발언으로 돌려줬다(`return text or stderr.strip()`, 코드로 확인).
- **본문이 빈 이유.** 호출 자체가 사용 한도 초과로 실패했다. 실패 메시지 8건 모두 오류 줄을 담고 있었고, 해당 호출 8회는 2.9~6.5초 만에 끝났으며 시간 초과는 0회였다. 같은 수집 실행에서 정상 응답한 Codex 호출 2회는 16.5초·17.6초였다(비공개 기록 DB).
- **처음 세운 가설과 정정.** 배너 첫 줄을 보고 처음에는 stdin을 닫지 않아 Codex가 입력을 기다리다 끝났다고 추정했다. 짧은 호출 시간과 오류 줄은 이 가설과 맞지 않아 원인에서 뺐다.

## 고친 것

- `stderr`는 발언으로 돌려주지 않는다. 본문이 비면 `stderr` 첫 줄을 담은 대괄호 오류 표시를 돌려주고(`is_error`로 구분), 서버는 이미 있던 오류 경로로 이를 대화 기록에서 빼고 경고만 남긴다(서버 코드는 이 저장소에 없다).
- 모든 CLI 참여자를 `stdin=subprocess.DEVNULL`로 실행한다. 기록된 실패의 원인은 아니지만, 서버의 stdin을 물려받으면 입력을 끝까지 읽는 CLI가 시간 초과까지 멈추는 위험이 있어 예방으로 둔다.
- 이미 쌓인 기록은 고칠 수 없어, 실패 메시지 뒤에 내려진 사회자 판정 기록 6건을 걸러 15건으로 분석했다(원본의 `is_contaminated()`).

## 검사

| 검사 | 무엇을 보나 | 종류 |
|---|---|---|
| `test_codex_failure_does_not_become_speech`, `test_codex_real_output_still_returned` | 실패 출력은 오류 표시, 정상 출력은 그대로 | 파서 단위 |
| `test_all_cli_members_close_stdin` | stdin 차단 설정이 코드에 있다 | 소스 문자열 |
| `tests/test_cli_runtime.py` 4개(2026-10-04) | 가짜 CLI를 실제 프로세스로 띄워 정상 출력, 사용 한도 실패, 열린 stdin을 물려받는 경우, 응답 없음(시간 초과)을 `Member.ask()` 전체 경로로 확인 | 런타임 |

런타임 검사는 옛 동작으로 되돌리면 실패하는 것을 확인했다(음성 대조). 오류 출력을 발언으로 돌려주게 되돌리면 사용 한도 검사가, stdin 인자를 빼 서버 stdin을 물려받게 하면 stdin 검사가 시간 초과로 실패한다.

## 한계

- 수치는 2026-09-23 시점 수집 실행 대화 8개 기준이다. 수정 뒤 실제 Codex로 같은 조건을 다시 재지 않았다.
- 파서는 본문이 빈 출력만 오류로 나눈다. 본문 표지 없이 글이 나오면 그대로 발언으로 돌려준다.
- 오류를 대화에서 빼자 사회자가 실패를 보지 못하는 문제가 남았다. 2026-09-24 대화에서 사회자는 호출이 실패한 Codex를 계속 다음 발언자로 골랐다.
- 걸러 낸 기록을 원래 내용으로 되살리지는 못했다.
